EMBERLINE is a 4v4 round-based tactical FPS built with three.js: bots that plant and defuse, an economy with a buy menu, rifles, SMGs, a sniper and grenades, on an original dusk solar-array map.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
